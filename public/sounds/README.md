# Sound Effects

This directory contains sound effects for the Werewolf AI game.

## Required Sound Files

- `vote.mp3` - Played when a player votes
- `elimination.mp3` - Played when a player is eliminated
- `phase-change.mp3` - Generic phase transition sound
- `day-start.mp3` - Played at the start of day phase
- `night-start.mp3` - Played at the start of night phase
- `victory.mp3` - Played when the player wins
- `defeat.mp3` - Played when the player loses
- `notification.mp3` - General notification sound
- `suspense.mp3` - Suspenseful sound for tense moments

## Notes

- All sound files should be in MP3 format
- Keep file sizes small for fast loading
- Recommended duration: 1-3 seconds per sound
- Volume should be normalized across all files
